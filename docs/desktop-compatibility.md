# 远程桌面兼容范围

Pi Console 的监控、服务与容器、文件和桌面是不同模块。能够连接 Linux 监控后端，不代表该系统已经具备本 App 可连接的图形桌面。桌面连接取决于远程桌面协议、桌面环境、认证方式和服务器配置，不能仅凭发行版名称判断。

| 服务器环境 | 当前集成情况 |
| --- | --- |
| 支持系统级 Remote Login 的 GNOME Remote Desktop / RDP | 已集成，通过本机 guacd 桥接；可选安装流程按 Ubuntu ARM64 环境验证，其他环境仍须检查组件版本、单元与权限 |
| Raspberry Pi OS 默认桌面 / VNC、WayVNC | 尚未集成 VNC 连接与认证适配；不能直接套用现有 GNOME 安装脚本 |
| 其他 Linux 桌面、xrdp 或其他 RDP 服务 | 尚未按不同服务完成配置、认证及兼容验证；协议名称相同也不代表现有安装器通用 |
| 无图形桌面的服务器或 Lite 镜像 | 可按条件使用其他监控和管理模块；需先另行部署图形桌面及适配的桌面服务，才有可操作的屏幕 |

Raspberry Pi 官方文档说明 Raspberry Pi OS 包含 WayVNC，见[官方远程访问文档](https://www.raspberrypi.com/documentation/computers/remote-access.html#vnc)。该系统的桌面服务与本项目当前 GNOME Remote Login 安装流程不同，现有客户端不会自动改用 VNC。

App 中“服务器桌面”是功能入口的通用名称。当前仍只使用已配置的 GNOME/RDP 链路；支持其他桌面后端需要实现对应协议配置、凭据处理和目标系统验证。项目没有自动替换用户已有桌面、VNC、RDP 或防火墙的逻辑。

## 网络连接

手机通过设置中的 HTTPS API 地址访问控制台，可以经公网、局域网或 VPN；Tailscale 是可选方案。域名或公网 IP 必须可达，证书须与地址匹配并受 Android 系统信任。实际是否允许公网访问由服务器的反向代理、网络访问规则和部署策略决定。

当前 GNOME 安装方案中的 RDP/guacd 链路仍限定在服务器本机及其可选私网范围。公网部署 App 的 HTTPS 入口，不要求同时把 RDP/guacd 端口暴露到公网。仓库的 Caddy 示例默认限制 Tailscale 来源，须按自己的网络策略调整后使用。

现有桌面方案的前置条件与命令见[部署说明](deployment.md)。

显示诊断在鼠标进入边缘或角落时自动保存最近 4 次聚合统计，至少间隔 1.2 秒；不主动打开控件或重绘，不保存截图、桌面文字、协议载荷或密码。断开桌面会取消后续采样。手动“画面检查”仍可能触发重绘，因此复制报告时会同时附上先前的边缘记录。窗口采样会裁去小数布局取整产生的越界部分，并保留固定失败代码；深黑色背景也纳入统计。统计用于定位，不能单凭全零认定画面正常，也不代表已验证实体手机的黑块问题。
